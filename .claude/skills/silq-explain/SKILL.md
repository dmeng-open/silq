# silq-explain — read-only learning mode

1. Ask which file or concept if not clear from current user message; otherwise inspect existing code and relevant step report.
2. Explain in Chinese: the purpose, input/output, data flow, important code paths and line references, one failure mode, and one contrast to an alternative approach.
3. Include one tiny hands-on exercise and two teach-back questions. Answer follow-ups interactively.
4. Do **not** edit implementation, reports, PROGRESS or roadmap; do not kick off a build or advance a micro-step.
5. Distinguish existing code from future architecture; do not invent file contents.
